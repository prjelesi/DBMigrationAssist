1. Executive Summary

DBMigrationAssist is a self-contained database migration readiness platform that lets customers and Microsoft engineers assess an entire database estate and receive scored readiness reports, AI-generated migration wave plans, and factory info-gather automation — all without writing code.


It integrates four components: a Power Apps Canvas App for input, a Docker Assessment Engine that runs locally in the customer environment, Microsoft Dataverse as the shared data store, and a Copilot Studio agent that generates natural-language reports.

7. Risks & Mitigations

RiskLikelihoodImpactMitigation
Customer firewall blocks Docker → Power Platform connectivity MediumHigh Use Azure Relay or ngrok; document both options in Phase 2.7
Oracle info-gather requires SQL*Plus / Oracle client install HighMedium Document Oracle Instant Client as prerequisite; offer manual gather fallback
Power Apps Custom Connector CORS/HTTPS issues with localhost MediumHigh Evaluate Azure Relay or self-signed cert with internal DNS in Phase 2.7
Dataverse API throttling (429) on bulk item push LowMedium Add exponential backoff retry in push_db_items_to_dataverse()
Copilot Studio generative answers hallucinate migration facts MediumHigh Ground all topics on migration-paths.json; disable open-web search for migration topics

8. Key Decisions

#DecisionRationale
D1Docker container (not Azure-hosted API)Must run in customer network to reach on-prem DBs via factory scripts
D2FastAPI (Python) for REST layerLightweight, async, auto-generates OpenAPI spec for Power Apps connector
D3Dataverse as shared storeNative to Power Platform — no extra infrastructure for Power Apps or Copilot Studio
D4MSAL client credentials for Dataverse authOnly non-interactive auth method suitable for a daemon container
D5Factory scripts kept as-is from upstream repoAvoids drift from Azure/cloud-accelerate-factory; orchestrator wraps them
D6Power Automate as Power Apps → Docker middlewareDecouples UI from Docker; handles async polling without blocking the canvas app
