Two Deployment Modes

☁️ Online (SaaS)

Hosted in Azure — customer opens browser
1
Customer registers at app.dbmigration.io
2
Downloads collector agent Docker image
3
Runs agent on their network with a registration token
4
Agent calls out to SaaS hub (HTTPS, no inbound firewall rules)
5
Results appear in browser — AI report generated

🏠 Self-hosted

Everything runs in customer environment
1
Customer runs docker compose up
2
Hub + React UI + PostgreSQL start locally
3
Collector agents register with local hub
4
Data never leaves customer network
5
AI analysis via Azure OpenAI OR local Ollama

Key Decisions
🚫
No Power Apps as primary UI
Kept as optional M365 add-on only — blocks self-hosted mode
🔄
Agent push model (not pull)
Agent calls hub outbound — no inbound firewall rules needed on customer network
🗃️
SQLite for self-hosted
No PostgreSQL required for simple deployments — single file, zero config
🤖
Ollama for air-gapped AI
Customers with no internet access can run Llama3/Mistral locally for report generation
📦
Pre-built agent image
Customer pulls a single image — no code, no build, just config via env vars
🏗️
Keep existing API contract
Phase 1 DB migration changes storage only — all endpoints stay identical
