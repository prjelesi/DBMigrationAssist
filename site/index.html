One assessment workspace

From estate inventory to an evidence-backed plan

Bring technical telemetry, stakeholder context, dependencies, and supporting documents together without granting the portal inbound access to customer networks.

01 / INVENTORY

Organize by project

Track databases, environments, criticality, communication edges, and portfolio groups in a project-oriented workspace.

02 / DISCOVER

Assess connected estates

Dispatch read-only collection jobs to lightweight agents that poll outbound and submit HMAC-signed findings.

03 / OFFLINE

Work across restricted networks

Generate database-specific collectors and upload validated JSON when a persistent agent is not appropriate.

04 / CONTEXT

Capture what queries cannot

Use versioned questionnaires and evidence attachments for ownership, downtime, compliance, and business constraints.

05 / ANALYZE

Ground reports in evidence

Build bounded report inputs from findings, documents, questionnaire answers, graph edges, and portfolios.

06 / GOVERN

Keep review in the loop

Persist source snapshots and report lifecycle state so practitioners can review and approve generated recommendations.

Designed for network boundaries

Collection starts inside the customer network.

The portal never connects directly to source databases. Agents initiate outbound HTTPS calls, execute engine plugins locally, and return structured findings.

1Per-agent pre-shared keys and HMAC-SHA256 request signatures.
2Read-only metadata collection; application rows are not queried.
3Evidence snapshots are persisted and content-hashed for report traceability.

Local quick start

Run the complete stack with Docker.

Build the .NET and React artifacts, configure local secrets from the example file, then start the portal, API, worker, PostgreSQL, and platform agent.

Full setup guide
PowerShell 7+
git clone https://github.com/prjelesi/DBMigrationAssist.git
cd DBMigrationAssist
dotnet restore src/AssessmentToolkit.sln
./build.ps1
Copy-Item .env.example .env
docker compose build
docker compose up -d
Assessment support is not certification. Validate engine versions, permissions, security controls, and generated recommendations in a representative environment before production use.
