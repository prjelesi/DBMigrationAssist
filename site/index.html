Designed for network boundaries

Collection stays close to the source.

The portal never connects directly to source databases. Agents execute engine plugins locally and initiate outbound HTTPS calls to return structured findings.

  • Local database credentials and read-only metadata collection; application rows are not queried.
  • Per-agent pre-shared keys and HMAC-SHA256 request signatures.
  • Offline collectors and validated JSON uploads when a persistent agent is not appropriate.

Build the artifacts, configure local secrets, and start the portal, API, worker, PostgreSQL, and platform agent with Docker Compose.

Before you start
Git, Docker 24+, .NET 8 SDK, Node.js 24 LTS + npm, and PowerShell 7+.

Full setup guide →
PowerShell 7+
git clone https://github.com/prjelesi/DBMigrationAssist.git
cd DBMigrationAssist
dotnet restore src/AssessmentToolkit.sln
.\build.ps1
Copy-Item .env.example .env
# Edit .env and configure local secrets before starting.
docker compose build
docker compose up -d

Images use pre-compiled output, so build first. Configure your .env values before starting services; see the setup guide for required settings.
